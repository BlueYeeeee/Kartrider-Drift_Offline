# Kartrider: Drift Offline

## 启动方法

1. 在 [Releases](https://github.com/BlueYeeeee/Kartrider-Drift_Offline/releases) 下载 0.2.6 完整压缩包并解压。
2. 保留解压后的所有文件和文件夹，双击 `KartDriftLocal.exe`。
3. 选择包含 `KartDrift` 文件夹的游戏目录，选择游戏语言。
4. 点击“启动本地游戏”。游戏运行期间保持启动器开启，退出游戏后再关闭启动器。

需要自行准备匹配版本的游戏客户端(参考链接: https://pan.baidu.com/s/1iTHawG-eX3E_amkXbt1ABw?pwd=c84q )。若提示客户端版本不匹配，请使用对应版本。
