# 竞速车改装共享映射表

已将249辆车的改装数据合并为9张齿轮子表、5种改装组合、77份不同的服务器重置性能。每辆车仅保存 `[重置性能ID, 改装组合ID]`，避免重复保存整套改装表。

## 合并结果

|改装组合|车辆数|差异|
|---|---:|---|
|P01|2|完整7项可调，瞬间加速器1～9档|
|P02|21|完整7项可调，瞬间加速器1～10档|
|P03|3|6项可调，没有漂移集气保留项；瞬间加速器1～10档|

|P05|219|4项可调：起步加速器、尾流、漂移集气保留、拖漂|

P04车辆：Kart:401010026、Kart:401010037、Kart:401010041（蓝布加迪）、Kart:401010057。赤月尖峰A2（Kart:401010017）属于P01。

P02和P04只有瞬间加速器第6档的重放增量存在差异，其余档位及其他齿轮表共享。它们的差异为浮点舍入层面，不据此认定设计倍率或车速不同。

## 文件

- `resources/data/local-sampled-speed-gear-map.json`：紧凑JSON数据；包含布局、重置性能、共享齿轮表、组合和车型映射。
- `vehicle-mapping.csv`：249辆车的ID查询表。
- `VEHICLE-DATA-VERIFICATION.json`：验证数量、大小、来源与产物SHA256。

逐车保存重置性能与改装规则的紧凑JSON为925937字节；合并后60671字节（约59.25KiB），减少93.45%。比较双方均不含缩进；原始抓包仍完整保留。

## 数据解释和验证

- `vehicles`引用`baselines`和`profiles`；`profiles`按齿轮名引用`tables`，每张表的`levels`仅包含已采档位。未出现的可调项目或档位不可外推。
- `f32_add`操作数使用4字节小端十六进制存储，按float32解释后相加并舍入到float32；`u32_add`按32位回绕，`or`用于布尔开关。
- 这些操作是能精确还原已采样本的共享重放规则，不代表已还原第三方服务器内部的计算步骤。
- 对全部9307份原始抓包独立回放，每份66个有效字段、243个有效字节完全一致。只忽略结构体填充字节；4辆特殊舍入车辆也逐字节通过。
- 重置性能保留服务器固定齿轮项，不能当成无任何固定加成的裸车。仅验收单项逐档变化；多项组合、固定项变化、引擎升级、道具模式及官服规则不在本次验收范围。
- 单机启动器的 `launcher-csharp/Performance.cs` 已接入该表，249辆车从实采重置基线按共享齿轮表计算。两辆未覆盖车型保留旧路径。未采档位、固定项变化与引擎变化继续拒绝，不外推未知值。
