# 单机兼容层改用原生模块

状态：采用；日期：2026-10-24；版本：0.2.9 预发布。

原单机启动器通过约 91.6 MB 的 Frida 运行库加载七个脚本。已有纯联机原生模块实现了其中五项必要兼容处理，另两项为启动/延迟诊断。单机缩小发行体积的同时，需要保留本地网关、SQLite 存档、装备、车辆性能、语言及塔影子。

复用已有原生实现，将单机启动改为先创建挂起的所属游戏进程、加载并检查兼容模块，再恢复主线程；登录完成后要求六项兼容标志全部就绪。移除脚本、通用脚本控制链和 Frida 依赖。本地业务和资源格式继续使用原实现，以减少重写及存档迁移风险。

代价是源码构建增加 Visual C++ x64/Windows SDK 工具要求，并保留针对固定客户端的进程内钩子及指令签名检查。运行时依赖静态链接，源码与许可证附带逐文件哈希。模块保留到所属游戏退出；移除 Frida 不意味着完全无需进程内适配或不会被杀软误报。

发布验证分别记录原生合同检查、单机存档/资源检查、真实 SDK 隔离验证和独立新存档登录。通过登录只证明该启动链能够完成本地认证；完整比赛结算、换车界面、语言视觉、塔实玩、断网冷启动及异机运行继续保留为未验收项。实现细节见 [原生兼容说明](../../native/README.md)。
